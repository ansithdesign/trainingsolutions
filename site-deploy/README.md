# Training Solutions homepage options

A static site with four homepage directions (Editorial, SaaS, Playful, Enterprise). Switch between them with the control at the bottom of the page. No build step.

## Publish on GitHub Pages

1. Create a new repository on GitHub, or use an existing one.
2. Upload the contents of this folder to the repository root: `index.html`, the `images` folder and `.nojekyll`.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, set **Source** to **Deploy from a branch**, choose your branch (usually `main`) and the `/ (root)` folder, then **Save**.
5. After a minute or two, the site is live at `https://<your-username>.github.io/<repository-name>/`.

## Linking to one option

Each option has its own address:

- Editorial: `…/#h`
- SaaS: `…/#j`
- Playful: `…/#s`
- Enterprise: `…/#t`
